Prompt design

From one-off prompt to reusable creative system.

I treat prompting as a design problem: define the target, lock what must stay consistent, expose useful variables, generate controlled variants and evaluate failure modes.

GOAL → creative intent CONSTRAINTS → what must remain fixed VARIABLES → what can change safely REFERENCES → mood, pacing, composition NEGATIVES → artifacts / failure modes EVALUATION → consistency, emotion, usability ITERATE → change one variable per pass
